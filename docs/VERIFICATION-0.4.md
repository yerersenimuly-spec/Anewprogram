# Проверка Line 0.4

Дата: 2026-10-03. Обычный native Android APK, не браузерный макет.

## Изменения

- Отдельный inbox с последними сообщениями каждого диалога, постранично из SQLite.
- Полноэкранная переписка с кнопками назад/звонок/меню и строкой ввода. Вкладки и постоянная панель безопасности удалены; проверка по-прежнему блокирует отправку до подтверждения.
- Локальные имена контактов, инициалы, отметки времени, сгруппированные сообщения и даты.
- Компактный номер на экране звонков; групповые настройки/шифрование не изменены.
- Сгруппированный профиль; служебные поля только в разделе администратора.
