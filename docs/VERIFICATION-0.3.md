## Найдено и исправлено на Android

`PRAGMA secure_delete=ON` возвращает строку. Выполнение через `execSQL` приводило к SQLiteException на API 26, что мешало открыть хранилище. Теперь используется `rawQuery` с проверкой результата; тест истории/Keystore прошёл. Проверка UI также выявила устаревшее accessibility-название кнопки; оно синхронизировано с отображаемым текстом.

## Ограничения результата

Проверки завершились до незапрошенного перезапуска sandbox и восстановления устаревшего снимка. Изменения восстановлены из сохранённой ветки и точных исправлений, затем заново проверены сборкой/локальными тестами. Файлы последних снимков утрачены; исторические снимки не предлагаются как текущий результат.

Ни software-эмулятор, ни выбор refresh-rate preference не доказывают 120 FPS или отсутствие lag. Проверены механизмы и поведение, **не измерено качество работы на 120-Гц физическом устройстве**. Не выполнены: реальный групповой аудиозвонок между телефонами через внешний LiveKit/TURN, сетевые переключения/фон на актуальных Android, публичные DNS/TLS/порты, независимый security-аудит.

В APK нет заранее развёрнутого публичного сервиса или поддельного номера. Номер появляется после регистрации на настоящем API. `mediaReady` означает корректно заданную серверную LiveKit-конфигурацию, а не внешнюю сетевую готовность. Для окончательно работающей службы связи необходимы серверы, доверенные pins и испытания устройств.
