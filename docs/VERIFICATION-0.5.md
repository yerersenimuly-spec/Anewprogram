- AOSP API 26: семь offline-инструментальных тестов, **`OK (7 tests)`**, 44.751 секунды. Проверены локальное удаление/tombstones, очистка очереди/диалога без затрагивания другого, миграция SQLite 1→2 без смены identity, пагинация, navigation и удаление сообщения долгим нажатием/диалогом.

Logout запретил дальнейшие вызовы.

## Защита и границы

Публичного или универсального admin-пароля в APK нет. Тестовый пароль существует только в test APK и loopback-only скрипте теста, не в выдаваемой app-сборке. Перед упаковкой временные debug-resources/CA удаляются и APK пересобирается. Админ-роль проверяется сервером для каждой команды, срок проверяется повторно перед исполнением очереди. Тайный жест только скрывает вход, не даёт права.

Журнал не содержит plaintext/ciphertext, IP, токены/секреты, номера участников и SDP. Он ограничен 100 последними событиями в RAM и не является долговременным security-аудитом. Для блокировки админ вводит конкретный номер, а список групп содержит только ID и число участников; содержание сообщений/медиа через панель недоступно.

Удаление **локальное**, не отзывает уже доставленную копию и не гарантирует уничтожение всех старых копий на физическом flash. Tombstone удерживает ID для подавления повторной вставки. Другой диалог и доверие/ключи не удаляются.

После успешных Android-проверок sandbox перезапустился с откатом. Код восстановлен из заранее сохранённой удалённой ветки, повторно проверен сборкой/локальными тестами. Файлы снимков утрачены, старые снимки не используются как текущее доказательство. Автоматическое закрытие UI по сроку сессии добавлено поверх проверенных серверных ограничений и проверено компиляцией/Lint, не ожиданием пяти минут на устройстве.

Не выполнено: покупка VPS/домена, публичное развёртывание, внешние TLS/TURN/UDP-порты, слышимый групповой звонок между физическими телефонами, независимый аудит. Настройка описана в `SERVICE-SETUP-RU.md`; приложение не подставляет фиктивный публичный сервер.
